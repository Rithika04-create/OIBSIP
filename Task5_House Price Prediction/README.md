## 📌 Project Overview

This project was completed as **Task 5** of my **Data Analytics Internship at Oasis Infobyte**.  
The goal: Predict house prices based on features like area, bedrooms, bathrooms, parking, and categorical variables.

## 📁 Dataset

- Dataset Name: "Housing.csv"
- Source: Housing Price Dataset
- Records: 500+ housing entries
- Features: Area, bedrooms, bathrooms, parking, furnishing status, air conditioning, guest rooms, and more
- Target Variable: House Price

## 🎯 Live Demo

> ✨ **Open `house_price_dashboard.html` in any browser** for an interactive, clickable dashboard experience!

## 📊 Key Features

- ✅ Data cleaning & encoding (binary + categorical)
- ✅ Exploratory Data Analysis (EDA) with stunning visuals
- ✅ Feature scaling & train-test split (80-20)
- ✅ Linear Regression model training
- ✅ Model evaluation (R², RMSE, MAE)
- ✅ **Interactive Visualizations** (Plotly):
  - 🧊 3D Regression Surface
  - 📈 Parallel Coordinates Plot
  - 🎥 Animated Scatter Plot
  - 📋 Executive Dashboard with R² Gauge
  - 🔥 Clustered Heatmap with Dendrogram
  - 📉 Residual Q-Q Plot & KDE

## 📈 Results

| Metric | Value |
|--------|-------|
| **R² Score** | 0.6524 |
| **RMSE** | ₹1,336,000 |
| **MAE** | ₹947,000 |
| **Top Feature** | Area (sq. ft.) |

## 💡 Business Insights

> 💎 *"Area is the strongest predictor of house price. Adding air conditioning and guest rooms significantly increases property value."*

## 🚀 How to Run

1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Open `House_Price_Prediction.ipynb` in Jupyter Notebook
4. Run all cells sequentially
5. Or simply open `house_price_dashboard.html` in any browser
